\section{The Shuffled2026 decoy set}
Real crystal structures give only positive examples of TCR recognition. To obtain physically-grounded
\emph{negatives} without any binding assay, we build \textbf{Shuffled2026} from the oriented Canonical2026
crystals (\texttt{tcren.shuffle} / \texttt{tcren shuffle}). Every complex is first superposed into the common
canonical MHC frame; we then keep each complex's \textbf{pMHC intact} (a real, correctly-presented peptide on
its own MHC) and graft on a \textbf{different} complex's TCR, drawn from a within-MHC-class derangement so no
decoy reproduces a real pairing. Because all structures share the one canonical frame, the graft is a
\emph{direct chain replacement with no per-pair alignment} --- unlike a pairwise MHC superposition, this lets
each grafted TCR keep its own native MHC--TCR docking angle, so the decoy set spans the real docking-angle
variance across the database. The peptide:MHC interface is untouched by construction (a built-in control:
$F_{\text{pep:MHC}}$ and $\Delta F_{\text{pep:MHC}}$ are invariant), while both the TCR:peptide and TCR:MHC
interfaces are mismatched. We generate $10\times$ decoys per pMHC.

\section{A conditional-linear-Gaussian Bayesian network}
We classify real ($y=1$) vs shuffled ($y=0$) with a Gaussian Bayesian network over the full fresh
\texttt{tcren} interface feature set (interface size and burial, dual-chain balance, the CDR-loop TCRen
energies $F$ and their poly-alanine $\Delta F$ for TCR:peptide / TCR:MHC / peptide:MHC, the TCRdock docking
geometry, and the chemical contact-type counts) together with the \textbf{MHC-class} label. A DAG is learned by
BIC hill-climbing on the within-class-centred, standardised features; the binary class $y$ and the MHC class
are then discrete parents of every feature node, shifting its conditional mean. Classification is the Gaussian
log-likelihood ratio $\log P(x\mid y{=}1)-\log P(x\mid y{=}0)$. The network is shown in
Figure~\ref{fig:bn}; performance under 5-fold cross-validation is in Figure~\ref{fig:curves} and
Table~\ref{tab:metrics}.
