## Remaining concrete findings / limitations

1. annotation/batch.py:264–277: capped _annotate catches every exception from private annotate_records and retries public annotate_sequences without a cap. A backend runtime failure can silently switch resource policy, rather than only missing capability triggering compatibility handling. Not changed; suitable surgical follow-up is narrow import/capability handling and propagation of runtime errors.
2. docking/chains.py:30–78: selection claims a connected, mutually contacting unit but max(candidate contact count) accepts all-zero candidates. An absent contacting receptor chain can be replaced by a disconnected copy. This is an algorithm guarantee mismatch visible directly in source; no real structure was rerun. Rejecting/omitting zero-contact candidates changes edge-case selection and needs a clear intended contract.
3. docking/angles.py:48–52: _domain_centroid docstring says first chain, but implementation pools all chains of a type. Peptide PCA also pools multiple peptides while taking first/last pooled coordinate for direction. ContactMap similarly includes multiple copies but its peptide_length is the first peptide length. Callers should select a single complex before these readouts; no new automatic selection introduced because it can alter existing outputs.
4. structure/io.py:105–128 retains every alternate conformer intentionally (legacy minimum-distance contract). pdb_lines/cif_lines at 498/543 deduplicate atom names and keep the first. Thus contacts can union mutually exclusive conformer positions while serialized/reloaded burial uses one. This is documented legacy behavior, not a license to change frozen descriptors; atom-count interpretation needs to say alternate positions, not simultaneously occupied atoms.
5. contact_types.py:1, 153–158: frozen v1 hydrogen_bond means nearest N/O atom distance <=3.5 Å, including N–N/O–O without donor/acceptor identity or angles. v2 improves donor/acceptor identity but remains distance-only (3.9 Å), with simplified protonation/tautomer assumptions. “DSSP-style” must not imply DSSP energy or angle-based hydrogen-bond determination. Preserve frozen values and describe as a proximity proxy.
6. docking/frame.py:_canonical_basis: only count>=3 is checked despite documented rejection of degenerate geometry. Coincident points yield zero singular-value denominator and arbitrary PCA axes; collinear points leave axes underdetermined. canonical_frame's broad exception fallback can also hide native alignment errors unless reference_id explicit. Not changed.
7. contacts/geometry.py early empty returns precede scope validation; invalid scope can return empty instead of raising for empty/noncontact inputs. representative atom kind other than cb selects CA rather than rejecting. Low-impact boundary consistency, not established-result defects.
