## Unresolved substantive findings / gates

1. P1 score.py:284-329, contact_map: p_any=1-product(1-p_j) is an independence approximation applied to COUPLED marginals. Marginals do not determine a union probability. Exact two-site example eta=(-2,-2), symmetric coupling4: weights=(1,e^-2,e^-2,1), each marginal=.5, exact union=1-1/(2+2e^-2)=.55960146, returned approximation=.75. Existing test test_contact_map_closes_the_pairs_with_poisson_binomial_p_at_least_one enshrines approximation, not coupled correctness. Source doc now names approximation; numerical behavior deliberately unchanged. Publication impact: any claim this is exact model contact frequency must change; replacing it with Gibbs-draw unions changes reported readouts and requires author-approved reproduction before promotion.
2. P1 ensemble.py:396-400,428-448: advertised warm start absent. After first coupled candidate state becomes None; next sampler restarts factorized and gets only candidate_burn=10 instead of burn=100. Uncoupled path restarts observed state each time with short burn too. Candidate order changes both stream and burn allocation. Smallest fix: carry last chain matrix explicitly or give each independent restart full burn; changes trajectories and requires measured-results gate. Do not silently change.
3. P1 sites.py:32-35,159-180,262-266: partner chain identity dropped from exported site schema; MHC region lengths keyed by region alone; pchain=role.par. Class-II chains can both have GROOVE_FLOOR, so same local position from distinct chains becomes indistinguishable and kernel joins can conflate them. Existing topology fix does not fix this separate source. Minimal fix needs stable chain identifier retained through available_pairs/site_codes/kernel and corresponding model/reproduction assessment.
4. P2 ensemble.py:432-434 checks only largest available position against candidate length, despite contract requiring par.len equality. Longer candidates accepted and unrepresented tail ignored; shorter candidates accepted when missing tail has no available site. It does not restrict sites to peptide partner, so MHC-region positions can be incorrectly threaded. Validate exact full peptide length and arm before scoring.
5. P2 model.py:184-188 n_parameters omits g_orient entirely and counts redundant one-body level coefficients as free parameters, including unobserved levels. Adding eight orientation coefficients leaves number unchanged. Clarify stored coefficients versus identifiable/free parameters and include orientation before using parameter-count comparisons.
6. P2 em.py:114-118,199-211 excludes g_orient from convergence vector and consistency blocks; orientation-only movement cannot prevent declared convergence. Add block consistently without refitting existing arrays.
7. P2 em.py:65-74,130-131: margin=0 documented as no latent sites, but sites exactly at cutoff enter mask and all-contact guard raises. Also guard refuses genuinely complete tiny datasets whose latent band happens to contain only contacts; counts alone cannot prove probe truncation. Explicit zero-margin path, and probe provenance needed for strong completeness guard.
8. P2 em.py:193: steps=0 leaves initial model but still divides n_contacts by draws, corrupting metadata. Reject steps<1 (selfcon already does) or return unmodified initial model.
9. P2 selfcon.py:61,333-343: contact_mass described as weighted total but computed plain p.sum(), and uncertain fraction likewise unweighted. Fitting/derivation do receive structure weights, so diagnostic measures a different population than fit. Apply same structure weights or label explicitly unweighted; existing measured trace values must remain recorded.
10. P2 em.py top-level: E-step samples full Gibbs posterior while M-step maximizes conditional pseudolikelihood, not expected full complete-data likelihood. This is a hybrid update, not ordinary likelihood EM, and has no EM monotonicity theorem. Selfcon explicitly disclaims ordinary EM correctly; em should equally distinguish its objective. Gibbs conditioning/clamping itself is correct.

## Claims and numerical-domain limits

- model.py:139 calls stored pseudo_loglik penalised; fit.py:203-205 stores unpenalized weighted log likelihood. Smallest fix is precise metadata doc; ridge is still included in actual IRLS objective.
- ensemble.py:15-18 incorrectly associates vanishing variance with independent model. Independent Var(Phi)=sum p_i(1-p_i)phi_i², generally positive. Covariance contribution vanishes under independence, not total variance.
- sample.py:150 calls -log histogram the Legendre partner of logZ(mu). Finite-system relation is log-sum-exp over count states, not an exact Legendre transform (saddlepoint/asymptotic qualification needed).
- score.py map_agreement doc claims JS=1 requires deterministic map. p=c*sigma, 0<c<1 yields identical normalized distributions and JS=1; level ratio records c. Deterministic requirement false.
- selfcon observation-field posterior requires an observation likelihood-ratio model. Adding logit P(sigma=1|distance) is not generally Bayesian conditioning on arbitrary prior unless that quantity is explicitly a likelihood ratio or reference prior is specified. Existing math defines a useful multiplicative field; probabilistic interpretation needs precise assumptions.
- fit.py:65-90 IRLS has no damping/line search/convergence status; ridge/free-intercept and invalid weights/one-class targets can yield singular or nonfinite fits. No measured failure established for shipped fits; this is incomplete domain validation, not evidence existing fit incorrect.
- sample.py mu_star fixed [-span,span] bisection does not verify bracketing; extreme targets inside sampled support can saturate at bound. Empty/negative sampling settings largely unvalidated; AIS steps=0 returns reference partition for coupled systems. Validate domains before claiming general numerical robustness.
- score.py:40-44 sort omits partner role/class in general joint/MHC identity, so equal-key rows need not have canonical order. Per-structure seed alone cannot guarantee permutation invariance there.

## Equations traced and consistent within stated domains

Energy E=-eta.sigma-0.5 sigma'A sigma, symmetric zero-diagonal kernel and conditional sigmoid(eta+A sigma); factorized logZ=sum logaddexp(0,eta); full-state exact enumeration; AIS incremental weights with coupling annealing and invariant block-Gibbs transitions; logZ estimate distinguished from unbiased Z estimator in sampler docs. Zero-sum gauge preserves fitted fields. Pseudolikelihood design neighbor counts include both edge directions and match energy conditionals. Linearity E[Phi]=sum p_i phi_i holds irrespective of coupling, ensemble empirical mean matches same-draw marginals. Map coarse-grained frequencies are counts/total draws (top_k output deliberately does not renormalize). Free-energy logsumexp and entropy mean(E)+logZ identities are algebraically correct for adequate sampling. Selfcon weighted-count expectation uses linearity correctly and explicitly does not promise a global maximizing objective. These are source/algebra checks, not convergence or empirical calibration verification.
