6. **P2, isotropic contact-loss probability is an approximation presented as exact.** _geom/geom.cpp:258 and mechanics/stability.py:8-11 use clip((delta-margin)/(2delta),0,1). For one atom pair at distance d and fixed isotropic displacement magnitude delta, exact loss is clip(((d+delta)^2-R^2)/(4*d*delta),0,1), for d,delta>0; R=cutoff. Synthetic d4.5,R5,delta1 gives shipped0.25 vs exact0.2916666666666667. For multiatom residue pairs even this single-pair formula is not exact for whether the entire contact is lost because another atom pair can keep it. Preserve values; describe exp_lost as linearized nearest-pair fragility surrogate, not literal expected contact loss. Catalogue/docs/tests currently encode the stronger reading. This is not a request to rerun or weaken standing discrimination results.

7. **P3, comparison does not validate chemistry scale.** surface_distance checks grid/extent/side but not scale; surface_complementarity checks grid/extent/sides only. KD and MJ phobic maps can therefore be compared as if same units. surface_map accepts any non-kd scale as MJ instead of rejecting unknown values. SurfaceMap stores scale, so validate it at these boundaries. No actual dataset effect established.

8. **P3, false global repack non-worsening guarantee.** _relax/relax.cpp:111-116 says inclusion of input conformer guarantees returned pose not worse. Each residue is optimized independently against ORIGINAL neighbors at :215-253, then their chosen conformers are combined. This guarantees each reported per-residue energy relative to frozen environment, not full assembled energy/no new clashes between simultaneously moved neighbors. Approximation is admitted in immediately following mean-field comment; narrow the guarantee to that objective. No synthetic worsening case or dataset effect measured, so mathematical limitation only.

## Other boundary observations

- balanced_weights accepts empty axes (division by zero for nonempty input), duplicate pdb.id (mapping overwrites rows after counting them), and duplicate column across axes (Polars duplicate select error). Its formula itself matches implementation. Default axes disjoint and metadata expected unique; no default-path defect proven.
- `alphabeta_ids` checks subset of TRA/TRB rather than presence of both. That matches its own docstring, but cannot by itself enforce project full-complex scope. Main structure CLI separately requires both CDR3s; no established shipped contamination.
- footprint `_h0_persistence_entropy` dense scipy MST treats zero-distance off-diagonal pairs as absent, so duplicate coordinate points need explicit treatment if allowed. No default structures inspected or synthetic verification performed for this edge.
- _fold weighted least-squares CCD update is mathematically correct for valid nonnegative weights and ordered kinematic bonds; negative weights and malformed bond order are not validated. No global optimum is promised (only monotonic local objective/convergence).
- _geom hash collisions add false candidate neighbors but exact distance filtering prevents false SASA burial; duplicates can waste time, not change result. Fixed Fibonacci sphere samples are rotation-approximate; surface height-map exact-equivariance claim concerns a separate frame-based ray caster.
- surface height-candidate search, top/bottom sign flip, smoothing and cell-area integration are internally consistent on inspection. Groove frame SVD has inherent degeneracy if floor is collinear/symmetric; finite and nondegeneracy input checks are absent.
